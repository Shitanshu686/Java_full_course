# Merge Sort

Merge Sort is a divide-and-conquer sorting algorithm.

## Algorithm

1. Divide the array into two halves.
2. Recursively sort both halves.
3. Merge the two sorted halves.

## Time Complexity

- Best Case: O(n log n)
- Average Case: O(n log n)
- Worst Case: O(n log n)

## Space Complexity

- O(n)

## Language

Java
